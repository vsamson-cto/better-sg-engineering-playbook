## Our Values Summary

### 1. Security First 🔐
Protect user data always. No exceptions. This is non-negotiable.

### 2. Quality Over Speed
Ship working code and improve iteratively. Don't let perfect be the enemy of good.

### 3. Document as You Go 📚
Help your teammates and your future self. Documentation is part of the work.

### 4. Review Everything 👀
Two sets of eyes are better than one. Code reviews catch bugs and spread knowledge.

### 5. Fail Fast, Learn Faster 🚀
Experiment boldly. Recover quickly. Share what you learn.

### 6. Volunteer-Friendly 🤝
Async-first, inclusive, respectful of your time. We value your contributions.
