# Welcome to Better.sg Engineering! 👋

## You're in the Right Place

Whether you're a seasoned engineer or just getting started, we're excited to have you contribute to Better.sg's mission.

## What Makes Better.sg Engineering Special?

### We're Volunteer-Powered
- **No judgment on availability** — Contribute when you can, how you can
- **Async-first collaboration** — We don't expect you to be online 9-5
- **Skill-building welcome** — Learning is part of contributing
- **Meaningful impact** — Your work directly helps Better.sg's mission

### We Embrace

**Modern Development Practices**
- Clean code principles that don't sacrifice clarity
- Security as a first-class concern
- Thorough code reviews and learning from them
- Testing as part of the process

**Experimentation & Learning**
- AI-assisted coding (GitHub Copilot, Claude, etc.)
- New tools and technologies explored thoughtfully
- Failure as a learning opportunity
- Questions encouraged and welcomed

**Transparency & Community**
- Open communication channels
- Documentation as a primary tool
- Onboarding that actually works
- Clear expectations and support

## A Few Things We Value

| Value | What It Means |
|-------|---------------|
| **Speed with Safety** | Move fast, but never sacrifice security or data protection |
| **Clear Communication** | Write things down; async collaboration requires it |
| **Inclusive Design** | Different skill levels, backgrounds, and schedules are strengths |
| **Owner Mindset** | Take responsibility for quality, but ask for help |
| **Continuous Growth** | Learning new things and sharing knowledge |
