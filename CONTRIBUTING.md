# Contributing to Better.sg Engineering Playbook

## 🎯 Purpose

This playbook is a living document. We welcome contributions from all Better.sg volunteers to help improve it.

## How to Contribute

### Found an Issue or Have a Suggestion?

1. **Open an Issue** on GitHub describing:
   - What needs improvement
   - Why it matters
   - Your suggested change (if applicable)

### Want to Contribute Content?

1. **Fork the repository** (or create a branch if you have access)
2. **Create a new branch**: `git checkout -b improve/section-name`
3. **Make your changes** following the guidelines in this playbook
4. **Submit a Pull Request** with:
   - Clear description of changes
   - Reference to any related issues
   - Examples where helpful

### Editing Guidelines

- Use clear, friendly language
- Follow Markdown formatting standards
- Use headings consistently (H1 for main sections, H2 for subsections)
- Include code examples where relevant
- Add citations and links to external resources

## Review Process

All contributions will be reviewed by the Better.sg CTO and engineering team. We aim to review contributions within 1 week.

## Questions?

Reach out to the Better.sg engineering team or open an issue!

Thank you for contributing! 🙏
